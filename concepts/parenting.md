# ADHD子育ての工夫

## 概要

ADHDのある子どもを育てる親たちから集められた「やってよかった」実践知のまとめ。専門的介入ではなく、家庭で取り入れられる環境・生活・勉強・コミュニケーション面の工夫が中心。いずれも「子どもの意志に頼らず、環境や仕組みで支える」発想に立つ。

以下の内容は @heyasupo 氏が親御たちから収集した41項目をカテゴリ別に整理したもの。

## 環境・生活の工夫

- 同じ靴下を複数買いして「ペア探し」の概念をなくす → [[environment-design]]
- 重めの布団（ウェイトブランケット）を使う → [[sleep]]
- トランポリンやバランスボールを家に置く（感覚刺激・運動の出口）
- タイムタイマー（残り時間が色でわかる時計）の導入 → [[time-management]]
- 部屋の視覚的ノイズを減らす（断捨離） → [[environment-design]]
- 物の定位置を写真やテプラで明示する → [[external-memory]]
- 翌日の準備ボックスを玄関に置く → [[forgetfulness-countermeasures]]
- **体育着で寝る**: 朝起きられないADHD傾向の子には、前夜に体育着で寝て、起きたらそのまま登校できる状態にしておく。朝の着替え判断を省き、目覚めの悪さに対処する。児童精神科医が提案する実践。^[raw/articles/tweet-1995472174837068093-sleep-in-pe-uniform-morning-routine.md]
- **レシート印刷でタスク管理**: スマホのタスクアプリはロック解除と同時に別アプリを見てしまうため、アプリで管理したタスクを朝食時にレシートプリンターで印刷し、筆箱に入れて学校へ持たせる。学校ではスマホ禁止のため紙が使え、手書きメモも可能。印刷音が朝の合図にもなる。^[raw/articles/tweet-2080841443212665173-receipt-print-child-task-management.md]
- GPSタグの活用（忘れ物・迷子防止） → [[external-memory]]
- イヤーマフやノイズキャンセリングの活用 → [[attention-control]]
- 服のタグを切る・肌触りの良い服を選ぶ（感覚過敏対策）
- 朝食にタンパク質を意識的に摂る
- 寝る前のルーティンを完全固定化する → [[sleep]]
- **寝る前の確認を「引き算」して、指さし・チェックリスト・固定ルーティンへ移す**: 夜に「時間割揃えた？」「宿題出した？」と矢継ぎ早に確認すると子どもが緊張して眠りにくくなるため、持ち物や準備をイラスト・チェックリストで見える化し、指さしだけで確認できるようにする。布団の約90分前に38〜40度のぬるめ入浴で体温を下げ、重みブランケットは体重10%前後・顔を覆わない範囲で試す、という睡眠環境のスレッドがある。事業者アカウント由来の提案であり、睡眠の持続的な困難は専門職へ相談する。^[raw/articles/tweet-2102717111227576616-sleep-environment-parenting-thread.md]
- やるべきことをホワイトボードで可視化する → [[external-memory]]
- リュックの中身をざっくり投げ込み収納にする（整理のハードルを下げる）
- スマートスピーカーで時間を知らせる（声かけの自動化） → [[time-management]]
- **移動手段を「境界のある場所だけ」に制限する**: 多動・衝動性が強く、三輪車や自転車で予測不能に遠くへ行くリスクが高い時期は、あえて自転車を所有せず、大きな公園の貸し自転車コースなど境界のある場面だけで乗せる家庭実践がある。子どもの能力否定ではなく、安全側へ倒す[[environment-design]]。^[raw/articles/tweet-1726008484150591650-child-bike-access-constraint.md]

- **「ストップ＆ゴーゲーム」で抑制を遊びで練習する**: 支援者が「ゴー（青）」で歩き、「ストップ（赤）」でピタッと止まる、を繰り返すだけの遊び。赤/青カードを掲示して視覚的に合図し、「止まれたら勝ち」にせず「みんなで10秒止まれたら全員クリア」の協力ルールにする。伝統的な「赤信号・青信号」遊びは幼児の実行機能（特に抑制）を高めるとされる（Diamond, 2013）。5〜10分で支援にも家庭にも使える。専門職投稿・理論引用あり。→ [[executive-function]]
- **「散らかしていい」ゾーン・分解専用箱・何もない壁・パーソナルテント・朝の光で環境から支える**: 発達特性のある子の家庭環境を、特性を「直す」のではなく強みを引き出す視点でまとめた10選の要点。散らかしてよいゾーンと分解専用おもちゃ箱で叱る場面を減らす、机の正面を無地の壁にして視界を減らす、光・音を遮れる小さなテントで休める場所を作る、朝食を窓際にして起きたら必ず光を浴びる導線にする、など。詳細は[[environment-design]]と[[sleep]]へ。^[raw/articles/tweet-2104168172861477285-ten-home-environment-settings-child.md]
- **失敗を「学び」として展示するボードと、体を動かす道具を置く**: 家族全員の「今週の失敗とそこから学んだこと」を貼るボードで失敗を日常化し、トランポリン等で学習前に短く体を動かすと集中課題へ入りやすくなる場合がある。手すり付き室内用・一度に一人・大人が見守るなどの安全配慮を守る。^[raw/articles/tweet-2104168172861477285-ten-home-environment-settings-child.md]

## 勉強面の工夫

- 宿題中にハンドスピナーやスクイーズなどの手遊びを許容する（刺激欲求を満たしながら集中）
- 宿題をゲーム化・クイズ化する（ドーパミンを活用）
- 勉強時間を10分くらいの細切れにする → [[task-initiation]]
- 集中できる環境を作る（パーテーションなど） → [[attention-control]]
- 提出物専用のクリアファイルを作る → [[forgetfulness-countermeasures]]
- スタンディングデスク（立って勉強）を認める
- **座位に固定せず、短い「動く学習枠」を作る**: まず1回5〜10分を目安に、立って問題を解く、声に出して読む、手でメモや絵を描く、のいずれかを選べるようにする。座って静かに聞くことを唯一の学習形態にせず、動きを課題処理へ組み込む。投稿者は肯定的な短いフィードバックも併用している。投稿由来の家庭実践であり、教育的・医療的効果を一般化するものではない。^[raw/articles/tweet-2090578808286200182-active-learning-short-blocks.md]
- **通信教育の教材は「人気」ではなく特性の条件から選ぶ**: ADHDは短時間学習（5〜15分）・ゲーム学習・自動採点、ASDはルーティン化・対話型アニメーション・明確な指示、LDは音声読み上げ・映像授業・無学年式、という目安で、その子の特性に合う条件から探す。^[raw/articles/tweet-2104405737455628559-choose-materials-by-trait.md]
- 教科書やプリントを拡大コピーする（視覚的処理の補助）

## 声かけ・コミュニケーションの工夫

- 指示は短く・具体的に・一つずつ出す（ワーキングメモリ負荷を下げる） → [[working-memory]]
- パーソナルスペースをフラフープなどで視覚的に教える
- 話す前にまず視線を合わせる（肩に触れる）
- 「ダメ」の代わりに「〜しよう」と肯定形で伝える
- 叱る基準を明確にする（命の危険・他害以外はスルー）
- できたことを実況中継して褒める（即時フィードバック）
- スモールステップで成功体験を積ませる → [[task-initiation]]
- クールダウンできる場所を作る → [[emotion-regulation]]
- 予告をしてから行動を切り替えさせる（切り替えの準備時間を与える）
- 1日1回は必ずハグやスキンシップをする
- 感情的に怒りそうになったら親がその場を離れる（親自身の感情調整）
- 望ましくない行動をあえて「無視」して注目を与えない
- 「助けて」「手伝って」という援助要請のスキルを教える
- 予定変更があるときは、わかった時点で早めに伝える
- 親自身の失敗談を明るく話して「失敗しても大丈夫」と伝える
- **共有カレンダー＋「チェックした？」の間接的声かけで、確認を本人のルーティンにする**: 家族でGoogleカレンダーを共有し、個人別のタスクカラー（例: 水色）を本人と一緒に設定する。カレンダーを見ない子には「今日は〇〇の日だよ」と直接指示せず、「今日はカレンダーをチェックした？水色の予定があった気がする」と問いかける。指示への反発（要求回避）を避けつつ、本人が自らカレンダーを確認する習慣を育てる。^[raw/articles/tweet-2104569477711241337-family-shared-calendar-indirect-prompt.md]

## 依存リスク予防：「受容 × 構造 × 合意」

ADHDの子はゲーム・スマホ・SNSにのめり込みやすく、思春期には飲酒・喫煙・薬物使用へ早めに関わりやすい。専門家投稿では、予防の軸を「受容 × 構造 × 合意」（オーソリタティブ養育）に置き、本人の意志ではなく外付けの枠で「やめ時」を支える。^[raw/articles/tweet-1971025987644371400-parenting-acceptance-structure-agreement.md]

- **受容（安心）**: まず受け止め、「大切にされている」と感じさせる。
- **構造（枠）**: ルールと生活の流れをあらかじめ決めて毎日同じように回し、抑制系が未発達な子どもへ大人が外付けのブレーキを提供する。
- **合意（共同決定）**: ルールを押し付けず、理由を伝えて子どもと一緒に決め、意思決定の主体者にする。

年齢別の実践例（投稿より）:
- 幼児期:「お風呂→歯みがき→絵本→就寝」の流れを壁に貼り、2択で選ばせ、タイマーで片づけたら即座に褒める。
- 小学生:「帰宅→手洗い→休憩5分→宿題→20分ゲーム」をホワイトボードに書き、守れたら翌日ゲーム＋5分。使用場所はリビング限定、充電は家族共通の置き場。
- 中高生: ①就寝90分前はノースマホ ②食卓は親子ともノースマホ ③充電はリビング、の3ルールを家族で合意し、ホワイトボード方式で更新。

親の態度は一貫性（今日はOK・明日はNGを避ける）、理由の説明、枠の中での選択肢、モデル行動（親もノースマホ）、話し合いによる合意更新。外付けの支え（スキャフォールディング）を少しずつ外すフェーディングで自己調整へ橋渡しする。研究知見に言及するが本文に個別書誌はなく、X投稿として低信頼度。→ [[executive-function]]・[[digital-interruptions]]・[[sleep]]
