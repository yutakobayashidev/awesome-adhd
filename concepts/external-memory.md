# 外部記憶

外部記憶は、頭の中で保持し続ける代わりに、紙・スマホ・タイマー・置き場所・他人の存在へ記憶や判断を預ける考え方。ADHD文脈では[[working-memory]]や[[executive-function]]の負荷を下げる実践として扱う。

## 投稿から抽出した型

- **見るだけで分かる場所**: 玄関のトレイ、ドア貼りチェックリスト、透明収納など、視界に入った瞬間に次の行動が決まる形にする。
- **即時メモ**: 「あとで思い出す」を期待せず、5秒以内にToDoへ入れる。未整理でもよく、まず忘却を防ぐ。
- **10秒以内の即時記録**: 思いついた瞬間に10秒でスマホに入れる。「後でまとめて書こう」とせず、気づいた瞬間に記録する方がADHDでは続きやすい。記録対象は「やること」「買うもの」「約束」「アイデア」「忘れたくないこと」「気分や体調」など何でもよい。^[raw/articles/tweet-2081967583767802139-ten-second-record.md]
- **時間の外部化**: タイムタイマー、アナログ時計、アラーム、終了時刻メモを使い、体感時間ではなく外部表示に判断を任せる。
- **人・場所への委譲**: ボディダブリングや場所トリガー式リマインダーのように、思い出す契機を自分の意志から切り離す。
- **端末の常時表示へ預ける**: [[tiimo|Tiimo]]のウィジェットやライブ表示のように、予定・タイマー・次の行動をホーム画面や腕時計に出し、思い出す作業を画面側へ移す。
- **作業履歴の検索化**: [[screenpipe]]のような道具は、画面・音声・アプリ上の出来事をあとから検索できる形にし、会議や作業の記憶を個人の頭から外へ出す。
- **返答形式への外部化**: [[i-have-adhd]] のように、エージェント側が次の行動・現在地・完了事項を毎回画面に出すと、利用者が会話の流れを頭の中で保持し続ける負荷を減らせる。
- **状態の外部表示**: 施錠確認できる鍵カバーのように、「やったか」を記憶から物の状態表示へ移す。
- **保管場所への外部化**: 重要書類を一箇所へ集めるなど、分類記憶ではなく探索場所の固定に頼る。
- **物理チェック盤への外部化**: 忘れ物チェッカーやホワイトボードのように、残タスクを手で切り替えられる物へ置く。完了状態が目に残るため、頭の中で「何が残っているか」を保持し続けなくてよい。
- **位置情報・自動化への外部化**: 外出時の照明・エアコン自動オフのように、思い出す契機をGPSやスマートホーム側へ渡す。
- **予定保持の外部化**: [[waiting-mode]]では、予定を忘れないよう頭の中で保持し続けることが一日を占有しやすい。複数リマインダー、支度リスト、前日準備で保持先を外へ移す。^[raw/articles/waiting-mode-the-conversation-2026.md]
- **朝の判断の外部化**: 服、持ち物、朝の順番を夜に決めて、朝は「読む／見る／なぞる」だけにする。判断を朝のワーキングメモリに置かない。
- **人の存在への外部化**: 通話をつないだ状態で片付けや洗濯を始めるなど、[[body-doubling]]を「開始の合図」として使う。記憶だけでなく、始動のきっかけも外へ置く。
- **予約・相手・終了確認への外部化**: [[focusmate|Focusmate]]は、作業予定を予約枠、相手の存在、最後の進捗確認へ預ける設計として読める。^[raw/articles/focusmate-homepage-2026.md]
- **AIへの計画外部化**: 長期タスクを自分の頭だけで保持・分解せず、生成AIに週・日・25分単位の案を作らせる。採用判断は本人が行い、診断・治療・人事法務判断には使わない線引きが必要。
- **ミスの状況リスト**: 試験・答練・提出前に、自分がケアレスミスしやすい状況だけを短いチェックリストへ残す。問題全体の写経ではなく、再発しやすい癖を直前に見る[[careless-mistake-countermeasures]]として使う。
- **A3用紙への全思考外在化**: 頭の中のモヤモヤやタスクを、デジタルや小さなメモ帳ではなくA3の大きな紙に書き出す。紙の広さが思考の自由度を上げ、出にくかったものまで出てきやすくなる。時間を決めて一気に書き出すことで区切りを作る。^[raw/articles/tweet-2080270807671201805-a3-journaling-brain-dump.md]
- **数字の見える化で報酬系を刺激**: 体重・貯金額・作業時間など定量化できるものをグラフ化し、毎日「変化」と「達成」を視覚的に確認する。ADHDの脳は伸びが見えると報酬系が反応し、過集中へ自然に入りやすくなる。記憶ではなく視覚フィードバックに動機づけを委ねる。^[raw/articles/tweet-2080201263778771041-hyperfocus-visual-progress-tracking.md]
- **「外付けメモリ」として堂々と使う**: ADHDの忘れっぽさは記憶力の低さではなく、注意が切り替わると脳内の情報が上書きされやすい特性。部屋に入って目的を忘れる、会話中に言いたいことが消えるといった現象は、ワーキングメモリの一時保存の仕組みの違い。メモを「外付けメモリ」と捉え、遠慮なく使う姿勢が重要。^[raw/articles/tweet-2081700413070512286-external-memory-justification.md]
- **5点の外部化システム**: ①リマインダーを思いついた瞬間に即登録（後回し厳禁）、②タスク情報を1か所に集約（メモアプリ/カレンダー）、③財布・鍵・イヤホンの定位置を固定、④思いついた瞬間にメモ、⑤朝・昼・夜の定時確認ルーティン。^[raw/articles/tweet-2081670676457591068-five-forgetfulness-systems.md]
- **会話の外部記憶化と「今も進行中」フレーミング**: 口頭での会話や約束はADHDの脳に残らない前提で、カレンダー登録、LINEや紙で「残る形」にし、定期的に「今も進行中の話」として再登場させる。過去の約束を思い出させるのではなく、現在進行形の話題として再提示することで時間的展望の弱さを補う。パートナー側の期待値調整（「覚えてたらラッキー」）も組み合わせる。^[raw/articles/tweet-2082068756692685166-calendar-visualization-keep-present.md]
- **カレンダーには予定名ではなく責任者（主催者）名を書く**: 「何の予定か思い出せない」問題に対して、イベント名ではなく主催者・責任者の名前を書く。忘れてもその人に聞けばわかる。相手も忘れているならその用事は重要度が低いという副次的判断にも使える。予定の内容記憶を人の名前という単一キーに圧縮する外部記憶術。^[raw/articles/tweet-1983393290721603589-calendar-organizer-name.md]

- **3秒メモ＋用途別リスト＋視界保持の6点セット**: 返信が必要なLINEは未読へ戻して通知時刻を設定する、買う物は店ごとのリストへ即入れる、洗濯機を回したら終了時刻にタイマーをかける、提出物・請求書は処理完了まで引き出しへ入れず視界に置く、思いついた用事は3秒以内にメモかカレンダーへ移す、毎日見る場所に『今日やること』を3個だけ表示する。『覚えておく努力』ではなく、忘れても戻れる環境を作る外部記憶セット。^[raw/articles/tweet-2085857313966166048-three-second-external-memory-six-tactics.md]
- **AI司令塔スレッドでプロジェクト記憶を一元化**: Claude Codeなど実作業エージェントへ直接突っ込む前に、別のClaude/GPT/NotebookLM等を『司令塔』として置き、自分の性質・過去の作業・プロジェクト文脈を共通ナレッジ化する。再開時は司令塔に『何やってたっけ』と聞けば、忘れた文脈から復帰できる。[[digital-adhd-support]]と[[task-resumption]]に接続する外部記憶設計。^[raw/articles/tweet-2085784093686669451-ai-command-thread-project-memory.md]
- **1日1行の時間ログ**: タイマーで時間を区切り、1日1行だけ行動・出来事を残す。時間感覚を頭の中の体感に任せず、後から見返せる短い記録として外へ出す。[[time-management]]の補助線として扱う。^[raw/articles/tweet-2086014654325911629-timer-one-line-record.md]
- **締切を紙とカレンダーへ逃がす**: やることを紙に書き、最初の一歩まで縮め、自分用締切を2日前にカレンダーへ登録する。締切直前の緊張ではなく、見える場所と通知に実行タイミングを預ける方法。^[raw/articles/tweet-2085867026594336842-deadline-paper-first-step.md]
- **関係維持を年3回通知へ外部化する**: 大事な人ほど丁寧に返そうとして先延ばしになる場合、切りたくない相手を5人だけ選び、誕生日＋任意の2回をカレンダー通知にする。送る文面も「元気にしてる？」程度に固定し、思い出す作業を愛情や罪悪感ではなく通知に任せる。[[relationships]]の実践として扱う。^[raw/articles/tweet-2086135350314061910-five-person-relationship-reminders.md]
- **消えるタスクで進捗を見せる**: 視覚化で作業速度が上がるタイプでは、タスクを書き出し、終わったら消すこと自体を短い報酬にする。音で進むタイプはタイマーやホワイトノイズを使い、短時間で聞こえる音を区切りにする。^[raw/articles/tweet-2086067401779548493-visual-audio-efficiency-styles.md]
- **言語化を「完璧な要約」ではなく断片列へ逃がす**: 会話や相談で言葉が詰まる時、頭の中で完成文を作ってから話そうとせず、「○○で、△△で、あと××」のように断片を並べるだけにする実践がある。これは話す内容の保持・整理を脳内だけで完結させず、断片列として外へ出す[[working-memory]]補助として読める。^[raw/articles/tweet-2086493971350766006-verbalization-list-fragments.md]
- **予定タスクと割込タスクを左右に分ける**: メモ用紙の左側に予定タスク、右側に割込タスクを書く。割込で元の作業記憶が上書きされる前提で、「今やるつもりだったこと」と「途中で発生したこと」を紙面の位置で分ける。^[raw/articles/tweet-2086889863656448054-left-right-task-split.md]
- **「組み合わせ」「探索」「時間感覚」を道具へ逃がす**: ケーブル一体型モバイルバッテリー、GPSタグ、カラビナ／ストラップ、バッグインバッグ、タイムタイマーのように、記憶する項目や探す範囲を道具側で減らす。ADHDでは「別売りケーブルを忘れず組み合わせる」「どこに置いたか思い出す」といった中間工程自体が負荷になりやすいため、工程を消す外部記憶として扱う。^[raw/articles/tweet-2086748673787199621-forgetfulness-tool-bundle.md]

- **思いつき専用の受信箱を置く**: アイデアや新タスクを思いついた瞬間に始めると、元の作業と新しい作業の両方が増殖しやすい。まず未整理の受信箱へ入れ、夜に「今日やる／今週見る／やらない」だけへ振り分けると、記憶保持と着手判断を分離できる。^[raw/articles/tweet-2087328213190217749-thoughts-inbox-evening-triage.md]

- **会議・中断の閉じ方をAIへ外部化する**: 会議後90秒以内にAIへメモを貼り、「決定事項」「自分がやるタスク3つ」だけへ圧縮する。中断前には「ここまでやった。次は○○から」と1行残し、再開時には「最初の3分でやること」だけを出させる。会議内容だけでなく、注意の残り・再開地点・最初の一手を外部記憶へ移す方法。^[raw/articles/tweet-2087416492082258023-ai-close-meeting-attention-residue.md]

- **仕事用の壁打ちトークへタスクを逃がす**: 始業時にタスク整理を行い、以後の新規タスクや割り込みは随時「壁打ちトーク」へ投げる。記憶保持を会話欄へ外部化できる一方、3連続・5分おきのような高頻度投入では処理抜けが起きるため、[[work-routines]]側で投入間隔やキューの上限も設計する。^[raw/articles/tweet-2087524179860246583-start-of-day-walltalk-task-capture.md]
- **メッセージ横断の単一受信箱＋AI補助**: Beeperのような統合メッセージアプリでLINE、X、Instagram、Slack、Signal等を一箇所に寄せ、AIに検索・返信案・未返信リマインドを担わせる実践がある。会話の所在と未返信を頭で覚えないための外部記憶だが、送信自動化・個人チャット連携は誤送信とプライバシーに注意する。^[raw/articles/tweet-2087489223616336198-beeper-message-hub-ai-reminders.md]

## 注意点

生成AI、受動センシング、服薬記録、画面・音声記録を使う支援は、記憶や判断の外部化を助ける一方で、行動データや生成AI入力データの扱いが問題になる。添付報告は、データ最小化、同意、削除、第三者委託の透明性を実装条件として挙げている。^[raw/articles/deep-research-report-ai-software-adhd-2026.md]


外部記憶は増やしすぎると、今度は管理対象が散らばる。置き場所、メモ先、リマインダー先は少数に絞る方がよい。

画面・音声の継続記録は、通常のメモより個人情報リスクが大きい。使う場合は、除外するアプリ・画面・URL、保存先、削除方針を先に決める。

## 受動記憶ツールとの接続

[[passive-memory-assistants-adhd]] は、画面キャプチャや音声記録を受動的に蓄積し、後から検索・再構成するツール群を ADHD 支援として評価する。外部記憶としては強力だが、キャプチャ量が増えると検索と整理の負荷が増すため、[[task-resumption]] や [[working-memory]] と組み合わせた設計が必要になる。
