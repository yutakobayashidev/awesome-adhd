# X投稿: 予定をしつこく再通知する Windows リマインダー「Naggie」

- 投稿者: TINMOON_LABEL（@tinmoon_label）
- 投稿日時: 2026-09-24 02:11:14 UTC
- 指標: 返信 1 / リポスト 0 / いいね 0
- 種別: 製品紹介（開発者アカウントによる、ADHD当事者と開発したという Windows 用リマインダーアプリの告知）

## 投稿本文（要点）

TINMOON代表のA星氏がADHD当事者で、出発前のXの投稿に夢中になってバスを乗り遅れることがある。そこから開発したのが Windows 用リマインダーアプリ「Naggie」。予定の名前・メモ・日時を登録すると、時間になるとデスクトップに通知カードが現れる。すぐできるならその場で「実行済み」、無理なら10分後・30分後・任意の日時へ延期できる。通知を見逃す・放置すると再通知が来る。自動再通知の間隔は3分・5分・10分から選択でき、静かに使いたい日はオフにできる。通知音は内蔵音のほか任意の音声ファイルを指定でき、通知カードの大きさも3段階、通知キャラクターも選択できる。メイン画面を閉じてもタスクトレイに残り、Windowsへのサインイン時に自動起動、ショートカットキーから予定を追加できる。予定と設定は自分のPC内に保存し、アカウント登録・広告・利用状況分析・クラウド同期はない。Windows 10/11対応、無料。

「一度知らせて終わりではなく、終わるまでちょっとしつこく付きまとう」ことを売りにしている。

## 取り込み時の注記

開発者アカウントによる製品紹介であり、効果は未検証。動作環境・アップデート・データ保存先は利用前に確認する。通知を「しつこく」すること自体が、通知過多で背景化しない範囲に絞る必要がある。
