# X投稿: 掃除は開始地点より終了条件を先に固定する

- 投稿者: @nakemono_shikou
- 投稿日: Wed Sep 09 08:01:07 +0000 2026
- 指標: いいね 1 / リポスト 0 / 返信 0

## 投稿本文

掃除中に目移りして大掃除へ拡大しやすい経験を踏まえ、開始前に範囲と終了条件を決める。具体的には「今日は机の上だけ」と対象を限定し、途中で気になった場所には触れずメモし、15分のタイマーを設定し、鳴ったら途中でも終了する。

## 抽出した実践メモ

掃除の着手地点よりも、範囲・時間・脱線時の記録先という終了境界を先に外部化する。これは個人の実践であり、医学的効果を示すものではない。
