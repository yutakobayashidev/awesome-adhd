# リセット衝動（全部捨てたくなる）への3つの対策

投稿者: ひにょ@ADHD脳力解放コーチ (@hirotsugu36)
投稿日: Fri Jul 31 02:46:45 +0000 2026
リポスト: 0, いいね: 0, 返信: 0

## 抜粋（対策部分）

ADHDの人に起きることがある『リセット衝動』には、主に3つの仕組みが関係している:
①「全か無か思考」で部分的な問題が"全部ダメ"になる
②拒絶への敏感さ（RSD）で「切られる前に切りたくなる」
③脳の容量が限界になり"強制終了"が起きる（認知的オーバーロード）

対策として大事なのは次の3つ:

**①重大な決断は、いったん保留する**
退職・別れる・縁を切る・アカウントを消すなど、元に戻しにくい決断は感情が強い時には実行しない。メールやメッセージも送信せずに下書きへ。「今は決めない」も立派な判断。

**②「今、脳がオーバーヒートしてる」と実況する**
「人生が全部ダメ」と決めるのではなく、「あ、今リセット衝動が来てる」「今は判断力より疲れが勝ってるかも」と一歩離れて見る。感情を否定しなくていい。「今の感情＝人生の結論ではない」と覚えておく。

**③信頼できる人に、判断を一時的に借りる**
頭がいっぱいの時は選択肢が「全部続ける」か「全部捨てる」の2つしか見えなくなりやすい。「今、全部投げ出したいんだけど、客観的にどう見える？」と誰かに相談する。自分一人では見えなかった「この部分だけ休めばいい」という第3の選択肢が見つかることがある。

小さなリセットから始める:
- スマホの電源を切る
- 今日は早く眠る
- 予定を一つ減らす
- 半日だけ一人になる
- 返信を明日に回す
