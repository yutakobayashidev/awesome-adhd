# X投稿 — 出来事トリガーで「あとで」を思い出す（前向き記憶の外部化）

## 本文

「やろうと思っていたのに、気づいたら忘れていた」を説明するキーワードとして、ADHDでは「前向き記憶（prospective memory）」の重要性が指摘されています。

ADHDの「先延ばし」は、意志の弱さよりも、「未来の自分にタスクを引き継ぐシステム」がうまく働きにくいという特徴で説明できる、という研究があります（Altgassen et al., 2019）。

前向き記憶は、
•「あとで◯◯しよう」と決めたことを、その「あとで」のタイミングで思い出して、実際に行動に移すための記です。

「19時になったら薬を飲む」「出勤前に1通だけメールを返す」も全部このシステムに乗っています。

成人ADHDでは、
•複雑な前向き記憶課題（いくつかの条件を同時に守る、段取りが必要な課題）が苦手になりやすいこと
•日常生活での「やるつもりだったのに忘れた」が多いこと
•それが「先延ばし」の多さを部分的に説明することが報告されています（Fuermaier et al., 2013; Altgassen et al., 2019）。

だとすると、目指すべきなのは

「ちゃんと覚えておく」ではなく、
「覚えておかなくていいように設計する」ことになります。

例えば：
•「19時になったら薬」ではなく、「夕食の皿を出したら薬が必ず目に入る置き方にする」
•「出勤前にメール」ではなく、「PCを開いたら最初にメール画面が自動で立ち上がるようにする」
•「明日の準備」ではなく、「玄関に“明日の自分ボックス”を1つだけ作って、そこに全部入れる」

時間を見る力に頼るのではなく、環境の変化（出来事）をトリガーにして思い出すように組み替えるイメージです。

## 取り込みメモ

時間ベースのリマインダー（「19時になったら薬」）から、出来事トリガー（「夕食の皿を出したら薬が目に入る置き方」）へ組み替える前向き記憶の外部化。具体的には、(1)服薬は皿と薬を一緒に見える位置に置く、(2)出勤前のメールはPC起動時にメール画面を自動表示する、(3)明日の準備は玄関に「明日の自分ボックス」を1つ作って全部入れる。Altgassenら2019・Fuermaierら2013を引用した解説投稿。時間感覚ではなく環境の変化を想起のきっかけにする設計で、既存の外部記憶・時間管理の考え方に接続する。診断・服薬の個別助言ではなく、低信頼度の解説として扱う。
