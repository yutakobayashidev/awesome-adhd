# X投稿: 待ち時間を忘れてよい「一工程5分以内」の作業ライン

- 投稿者: りくとん@ADHD×コンビニ就労（@a_rikuton）
- 投稿日時: Mon Sep 07 19:39:11 +0000 2026
- 指標: 返信 0 / リポスト 0 / いいね 2

## 投稿本文

うちの業務のタスクリスト、例えば「オーブン清掃」ひとつで書くところを、「オーブン冷却」とその1時間後の「オーブン清掃」にリストを分けてる。

他にも【ポットのクエン酸洗浄】で済ますとこを、

19時クエン酸入れる、
20時水洗い
21時捨て水、お客様用の湯を沸かす→一台目完了、のように段階ごとに3工程にタスクを分割しています。

理由は、冷却の50分間に清掃を忘れていいように。お湯が沸くまでの40分間、ポットのこと忘れていいように。

あれこれ業務を同時進行しているように見えて、全ての工程を１ラインに整えています。基本、一工程5分以内。

もちろんトイレの壁清掃とかまとまった時間を要する業務もあるんだけど、それはそれとしてシングルタスクなので1ラインを乱さないわけで。

タスクの中で「待ち時間」を作らないのが、シングルタスク化の肝だと思ってます。

## 取り込みメモ

これは公開された個人の職場実践であり、ADHD一般への効果を示す医学的根拠ではない。待ち工程を「次に何時に戻るか」が明示された独立タスクに分け、保持をリストへ逃がす点を、外部記憶・時間管理・仕事のルーティンの実践例として扱う。
