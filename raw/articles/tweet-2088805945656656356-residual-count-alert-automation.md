# 予約・在庫型の仕組みは「残数アラート」まで含める

## Tweet text

> 毎日投稿が出ていたので、仕組みが動いていると思い込んでいた。動いていたのは仕組みではなく、いつか一度だけ積んだ10枠の予約だった。
> 
> 10枠は8日で尽きた。その先に残っていたのは、4日後の1本きり。棚が空になっても、誰にも何も知らせない。予約の一覧は、空でもきれいに表示される。空になった日に音は鳴らない。棚が満杯のときと空のときで、画面の見た目がまったく変わらないからだ。
> 
> これは自分の作り方の癖でもある。積むところまでは一気にやる。10本まとめて用意して、並べて、満足して閉じる。減っていく側の管理は、その日の気分の外にある。だから残り何本かを見る習慣が生まれない。
> 
> 僕は長いあいだ、自動と手動の違いは仕組みの有無だと思っていた。違いは、補充する人が要るかどうかだった。積んだ分だけ出るものは、出ているあいだも手動のままだ。
> 
> いま置いているのは、残り本数を数える仕掛けだけ。中身の良し悪しは見ない。残りが3本を切ったら知らせる、それだけで棚は空にならない。
> 
> 続く仕組みかどうかは、出ている様子ではなく、減っていく残数が見えるかで決まる。

## Extracted practical tactic

予約投稿や在庫のように「積んだ分だけ減る」仕組みは、出力が見えている間も補充が必要なら手動運用のまま。残り本数を数え、閾値（例: 残り3本未満）を切ったら通知する仕掛けを置くことで、空になる前に補充へ戻れる。
