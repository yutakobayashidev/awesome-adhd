# X投稿: 60点で止める仕事設計

- 投稿日時: Tue Sep 08 04:13:17 +0000 2026
- 投稿者: いそでぃ（@__isod）
- 反応: いいね 0 / リポスト 0 / 返信 0

## 本文

ADHDは0か100なので、60点（及第点レベル）の出し方をみんな知らないのもあるんですよね。

私も仕事ではほんの1ピクセルのズレが気になって延々と調整してますし、資料の細かい言い回しを誰も気づかないレベルで変えたりしてます。

そうすると他にやらないといけないタスクに使う時間がなくなり、結果的に休息時間や睡眠時間を削って頑張るしかなくなります。そして間違いなく倒れます。

自分がそうならないためにやっている工夫は、
・毎朝10分時間を取り、そこで決めたタスクしか基本やらない
・イレギュラーがあっても対応できるバッファを3時間作る（予定をギッチギチにしない）
・◯時以降は仕事をしないルールにする

## 取り込みメモ

毎朝10分で当日の対象を決め、それ以外を基本的に行わない。イレギュラーに備えた3時間の余白と、仕事を終える時刻を固定するという、完璧主義で範囲が際限なく広がるのを防ぐ当事者の仕事設計。個人の実践であり、医学的根拠や一般的な職場ルールではない。
