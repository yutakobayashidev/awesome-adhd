# X投稿: すき間時間を長さ別の候補リストにする

- 投稿URL: https://x.com/sodatun063/status/2091408866466754801

## 本文

さらに、
5分 → ゴミ・メール・準備
15分 → 食器・片づけ
30分 → 散歩・書類整理
と「すき間時間リスト」を作っておく。
もちろん、休憩を選んでもOK。
空き時間は全部埋めなくても大丈夫です。

## 注記

個人による生活上の実践提案であり、医療的・臨床的効果を示す資料ではない。
