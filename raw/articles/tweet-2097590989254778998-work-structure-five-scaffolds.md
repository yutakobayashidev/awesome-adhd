# X投稿: 職場の仕事を人に合わせて構造化する

- 投稿者: @a_rikuton
- 投稿日: Wed Sep 09 07:40:37 +0000 2026
- 指標: いいね 4 / リポスト 0 / 返信 0

## 投稿本文

ADHDの人へ「もっと集中して」「ちゃんと覚えて」「ミスしないように気をつけて」と言うだけでは仕事はできるようにならない、とする投稿。コンビニのように中断が多い職場を例に、指示を一度に詰め込まない、やることを見える化する、優先順位を明確にする、作業の順番を固定する、ミスしても立て直せる仕組みにする、という五つの仕事設計を挙げる。

## 抽出した実践メモ

努力や監視を増やす代わりに、指示量・可視化・優先順位・固定手順・復旧手順を仕事側へ埋め込むという個人の実践的な提案。医学的・臨床的効果を示すものではなく、職場の安全、業務品質、就業規則と合わせて検討する。
