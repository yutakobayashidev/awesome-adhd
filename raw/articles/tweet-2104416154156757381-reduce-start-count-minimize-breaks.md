# X投稿 — 開始コストが高いから開始回数を減らす（休憩を最小化して過集中でブチ抜ける）

## 本文

ADHDは開始コストが尋常じゃないレベルで高いので、順接的に開始回数を減らす必要がある。要するに、一度始めたら戦闘不能になってブッ倒れるまで、ハイパーフォーカスでブチ抜ける必要がある、ということ。こまめな休憩とかゴミ。開始回数が増えるので、結果的にトータルの労力は上がり成果は下がる。

## 取り込みメモ

ADHDは開始コストが非常に高いため、開始回数を減らす必要があり、一度始めたら倒れるまで過集中で突き進み、こまめな休憩を挟まない方が総労力が下がり成果が上がるという当事者投稿。既存の「休憩を入れる」型の過集中対策とは逆の立場を含むため、単一投稿の低信頼度の個人実践として扱い、医学的根拠とはしない。
